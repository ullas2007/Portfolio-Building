Setting up the C/C++ environment on Windows 11 went smoothly, but I encountered a minor hurdle when configuring the compiler path. Initially, the terminal returned a "'gcc' is not recognized" error because I had opened the command prompt before updating the system's PATH variable. After adding C:\msys64\ucrt64\bin to the PATH and opening a brand-new terminal window, the compiler was successfully recognized. I verified the installation using the gcc --version command and successfully ran the hello.c file. The source code and execution screenshot have been committed to my GitHub repository under the Activity-1-Dev-Environment-Setup folder.
